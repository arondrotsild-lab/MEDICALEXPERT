# MedExpert Turkey

Сайт медицинского консьерж-сервиса MedExpert Turkey: лечение в Турции под заботой команды врачей.

- 7 языков: русский, английский, немецкий, турецкий, арабский (RTL), испанский, итальянский
- 12 направлений с видео, отдельный блок стоматологии, команда врачей, путь пациента, FAQ, форма заявки
- Статический сайт: `index.html` + папка `media/` с видео
